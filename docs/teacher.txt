<교사용 대시보드 (수학 수행평가 관리)>
1. 목적 및 성격: 수학 과목 전용 수행평가 통합 관리 (세특 기능 전면 삭제)
   - 해당 과목(청계중 3학년 수학) 교사의 과목 및 학급만 볼 수 있도록 한정

2. 주요 기능 플로우:
   ① AI 문항 출제:
      - 교과서 목차(단원), 페이지 범위, 문제 수, 난이도(하/중/상)를 입력받아 AI 자동 생성
      - 성취기준 코드([9수01-01] 등) 연계 객관식 및 서술형 문항 검토 후 선생님이 [수행평가 문제 최종 확정]
   ② 수업시간 일회성 시험 코드 배포:
      - 문제 확정 후 [일회성 코드 생성] 버튼으로 대형 PIN 발급 (예: MTH-7429)
      - 학생들에게 공유하여 즉시 시험 응시 진행 (실시간 답안 제출 현황 카운트)
      - 시험 종료 버튼 클릭 시 일회성 코드는 즉시 만료(EXPIRED)되어 영구 재사용 불가
   ③ 학생 수행평가 관리 테이블:
      - 학년, 반, 번호, 이름, 응시상태, AI점수, 교사확정점수 테이블 구성
      - 각 컬럼별(반 선택, 번호 검색, 이름 실시간 검색, 채점상태) 필터링 지원
   ④ 2단계 평가 (AI 1차 채점 -> 교사 2차 점수 확정):
      - 학생들이 제출한 수행평가 답안은 일차적으로 AI가 자동 채점 (문항별 부분점수 및 근거 산출)
      - 선생님은 2차 최종 평가자로서 AI 판정 확인 후 점수 직접 가감/조정(+ / -) 및 최종 확정
