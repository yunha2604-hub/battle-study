아레나 게이밍 트랙 표준 인증 순서도 (중학교 정보 교과 기준)

회원가입 없는 즉시 참여, 승점 보존 카카오 연결, 소속 학교 공식 인증의 3단계 인증 구조를 정보 교과서 표준 기호로 도식화한 순서도입니다.

중학교 정보 교과 순서도(Flowchart) 표준 기호 범례
1. 타원/캡슐 (Terminator)

온보딩 시작과 최종 공식 인증 완료 (2.0px 외곽선)

2. 마름모 (Decision)

카카오 연동 여부, 인증 수단 및 충족 검증

3. 평행사변형 (Data I/O)

닉네임/학교 입력, 카카오 로그인 정보 입력

4. 직사각형 (Process)

즉시 참여 자격 부여 및 계정 저장 처리

5. 강조 외곽선 (Highlight)

GPS·동문 검증 수단 및 최종 공식 인증 완료 라인
