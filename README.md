# [배틀스터디 (Battle Study)](https://yunha2604-hub.github.io/battle-study/)

### 실시간 퀴즈 배틀 & 수행평가 관리

학교를 대표해 전국 학생들과 맞붙는 실시간 퀴즈 배틀 서비스입니다.

친구들과 게임을 할 때는 밤을 새워도 등급을 올리려 합니다.
배틀스터디는 그 집중력을 공부로 끌어옵니다.

---

## 왜 만들었나

| 대상 | 문제 |
|---|---|
| 학생 | 혼자 하는 공부는 금방 질린다. 게임처럼 경쟁 상대가 있으면 다르다. |
| 교사 | 문항 출제와 수행평가 채점이 쌓이면 수업 준비할 시간이 없다. |

---

## 무엇을 만들었나

학생용 모바일 앱과 교사용 PC 웹이 실시간으로 연동되는 교육 서비스입니다.

- 학생은 쉬는 시간에 타 학교 학생과 1:1 퀴즈 배틀 → 내 점수가 학교 순위에 실시간 반영
- 선생님은 AI로 수행평가 문항을 출제하고 PIN을 배포 → AI 1차 채점 후 교사가 최종 확정

## 기능 정리

### 학생용
| 기능 | 설명 |
|---|---|
| 실시간 1:1 배틀 | 수학 문제로 타 학교 학생과 매칭(MVP). 정답 시 상대 체력 감소, 제한 시간 30% 이내 정답 시 크리티컬. 국어·영어는 지원 예정 |
| 학교 대항전 | 반·학교 단위 팀 줄다리기 방식의 단체 배틀 |
| 전국 학교 랭킹 | 개인 승점이 소속 학교 점수에 합산되어 학교 간 순위 경쟁 |
| 오답 던전 | 번개 에너지(최대 5개)는 매칭 1회당 1개 소모. 틀린 문제를 푼 뒤 던전을 클리어해야 충전 |
| 전적 분석 | 과목별 정답률, 최근 경기 기록, 티어와 LP 변동 확인 |
| 수행평가 응시 | 교사가 발급한 PIN으로 입장. 흰색 시험지 화면, 닉네임 익명화, 화면 이탈 시 0점 처리 |

### 교사용 (수학 수행평가로 시연, 국어·영어는 지원 예정)
| 기능 | 설명 |
|---|---|
| AI 문항 출제 | 단원, 페이지 범위, 문항 수, 난이도를 입력하면 성취기준 코드와 연계된 객관식·서술형 문항 생성. 교사가 검토 후 확정 |
| 시험 코드(PIN) 관리 | 확정 후 일회성 PIN 발급, 실시간 제출 현황 확인, 종료 시 코드 즉시 만료 |
| 학생 관리 테이블 | 학년·반·번호·이름·제출 상태·점수·평가 상태 확인, 이름·반·번호·상태별 필터 |
| 2단계 채점 | AI 1차 자동 채점(문항별 근거 포함) → 교사가 점수 조정과 피드백 작성 후 최종 확정 |

## 지원 교과목

현재 MVP는 수학으로 구현되어 있으며, 중·고등학교 핵심 3대 교과(**국어·영어·수학**) 전체로 확장할 예정입니다. 각 과목의 문제 특성에 맞춰 5초~90초의 차등 제한 시간을 적용해 속도감 있는 퀴즈 배틀을 제공하는 것을 목표로 합니다.

| 교과목 | 주요 출제 영역 | 문제 유형 및 제한 시간 특징 |
|---|---|---|
| **국어 (Korean)** | 한글 맞춤법, 어문 규정, 근현대 문학 | 지원 예정. 10~15초 숏폼 퀴즈 위주 |
| **영어 (English)** | 필수 어휘(Vocab), 핵심 문법(Grammar), 구문 독해(Syntax) | 지원 예정. 5~30초 제한 시간 |
| **수학 (Math)** | 기초 연산, 삼각비, 다항식/방정식 (보스 배틀) | MVP 구현 완료. 10초(기초 계산) ~ 90초(보스 배틀 고난도) 난이도별 차등 배정 |

- **교육과정 및 성취기준 연동**: 교사용 웹에서는 2022 개정 교육과정 성취기준 코드(예: `12영01-05`, `12수01-02`, `12국01-02`) 및 주요 교과서 출판사(미래엔, 천재교육, 비상, EBS, YBM)와 연계되어 교과서 단원 기반 문제 출제를 지원합니다.
- **확장성**: 수학 MVP를 기반으로 국어·영어로 확장하고, 이후 개념 확인형 퀴즈 출제가 용이한 사회·역사(한국사)·과학 등 탐구 영역까지 넓힐 수 있습니다.

## 시작하기 (실행 방법)

별도의 백엔드나 환경변수 설정 없이 바로 실행할 수 있는 프로토타입 웹 애플리케이션입니다.

### 1. 사전 요구사항
- **Node.js** 20.x 이상 권장
- **npm** (또는 yarn, pnpm)

### 2. 패키지 설치
```bash
npm install
```

### 3. 개발 서버 실행
```bash
npm run dev
```
실행 후 웹 브라우저에서 [`http://localhost:3000`](http://localhost:3000)으로 접속합니다.

### 4. 빌드 및 프로덕션 실행
```bash
# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start
```

### 5. 코드 검사 (Lint)
```bash
npm run lint
```

## 앞으로

우선 청계중학교에서 시작해 주변 학교로 퍼뜨릴 생각입니다.
학교가 많이 참여할수록 전국 랭킹 대결이 더 재밌어지기 때문에,
한 학교가 쓰기 시작하면 경쟁 학교도 따라오는 구조입니다.

비싼 학원을 다니지 않아도, 스마트폰 하나로 전국 친구들과 경쟁하며 공부할 수 있는 것 —
그게 이 서비스를 만든 이유입니다.
